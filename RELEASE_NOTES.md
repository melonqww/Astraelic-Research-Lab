# Первый выпуск лаборатории

Первый выпуск представляет AR-1: сравнение равномерной выборки файлов и допустимых учебных окон. В комплекте русский отчёт, девять парных доменных результатов, бюджеты шести run, графики, численные исходные измерения и код пересчёта анализа без модели.

При одинаковом числе обучающих токенов снижение отношения средних BPB составило 4,02% / 3,34% / 1,85% для английского / русского / кода. Вывод ограничен одной небольшой архитектурой, техническим корпусом и фиксированной development-панелью. Веса, исходные тексты корпуса и полноценная среда повторного обучения не включены.

В репозиторий включается только публичный комплект laboratory/: отчёт, численные измерения, графики, код анализа, тесты и лицензии. Техническое рабочее пространство и исходные веса остаются локальными.
